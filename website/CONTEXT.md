# Website terminology

- **MacroMachine:** a WorldPainter plugin filling capability gaps in WorldPainter and World Machine, with precise manual editing tools and reusable global operations. It is not a World Machine integration; World Machine is not a dependency.
- **Macro:** a reusable, ordered sequence of global operations assembled visually; programming is not required.
- **Action:** one operation within a macro, connecting an input, an operation, and an output.
- **Action Filter:** the affected-block restriction shared by subsequent actions, including nested macro actions.
- **Macro Selection:** a MacroMachine layer; distinct from WorldPainter's ordinary selection.
- **CityLayer:** a layer type for deliberate placement of chosen schematics. Individual layers can have user-chosen names.
- **3D Preview:** an export-based surface view used while editing, not a Minecraft client or a complete-export guarantee.
- **WorldPainter project:** the editable `.world` file, which may depend on plugin-specific layers.
- **Exported Minecraft world:** the result of a normal WorldPainter export; does not require WorldPainter or MacroMachine to play.
